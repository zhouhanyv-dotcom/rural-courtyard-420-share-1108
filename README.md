# 420㎡农村自建房 · 公开三维展示

可旋转的三维模型、第一视角步行与院内自动导览、设备识别、水电分路、资源试算和中文说明。静态网站，无需登录。

`index.html` 进入 `viewer/`，资料在 `documents/`。模型使用标准 glTF 外部buffer，保持与原生模型一致的几何。

此仓库仅包含用户授权公开的展示资产和说明；不包含可编辑BLEND、私有日志、账号凭证或历史草稿。

这是概念空间和运行预算，实际工程仍需现场核定。


正式展示版已发布：2026年11月8日。默认全院完整外观；楼层剖视、48项设备识别、水电说明与检修视图保留。手机提示“请用电脑打开”。

点击“第一视角”进入步行，或打开 `viewer/?v=first-person-1108#walk`。WASD/方向键移动，拖动鼠标转头，Shift加速；可选择快速到达和自动逛院子。操作说明见 `documents/第一视角漫游.html`。
