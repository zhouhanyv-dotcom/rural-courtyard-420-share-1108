# 熟悉的食物与日常生活

用户希望末日仍能吃到熟悉的现代食品，把味道作为与原来生活相连的线索。这是本版的设计主线；不是单纯多堆肉。保留正常厨房、电脑与离线娱乐、书、狗的陪伴和规律作息，减少每天只围着设备转。

## 三种温区

- 常温：既有525kg基础食品保留。咖啡、茶、可可、香料、汤底、咖喱、酱料与巧克力利用原奶粉、坚果、糖、罐头等类别及调味小箱；具体到期以标签为准，热量不重复计入基础保障。
- 冷冻：4.32m²小冷库，设计储藏−18°C或以下。190kg多样库存按原切肉80kg、鱼虾20kg、饺子/馄饨/包子/披萨等半成品35kg、蔬果25kg、适合冷冻的奶酪黄油/甜品10kg、烘焙10kg、冰淇淋10kg分区。它们是类别和重量预算，不是已验证某家店具体商品。
- 冷藏：厨房冰箱≤4°C，初始喜欢的乳品、熟食等约10kg按每件标签优先吃；不把它们当作能放730天。需要冷冻的优先买厂商明确标注可冷冻/速冻的版本，不统一把冷藏成品放进冷库便当成延长两年。

山姆等渠道可以买现成食品。采购时逐件记录SKU、净重、包装尺寸、生产日期、标签期限、温区、解冻/烹饪要求、位置及计划享用日。实际SKU与到期尚未确定，不能先说“都能放两年”。

持续−18°C冷冻下，食品安全与风味品质是两件事；两年后的口感、质地和氧化损耗不作保证。尤其烘焙、奶制甜品、冰淇淋和某些半成品优先按标签与官方质量建议安排。冷冻不会把已污染或已变质的食物恢复正常。基础常温完整食物仍覆盖主能量，冻品不成为唯一生存依赖。

## 一周有一点变化

| 日子 | 想吃的一餐 | 留给自己的事 |
|---|---|---|
| 周一 | 家常肉菜饭 | 看一集熟悉的剧，整理房间 |
| 周二 | 饺子、馄饨或汤面 | 听音乐，陪狗活动 |
| 周三 | 咖喱饭、一锅炖菜 | 写几句日记，记下今天的味道 |
| 周四 | 鱼虾配米饭或面 | 翻照片、读书 |
| 周五 | 披萨或喜欢的半成品 | 电影夜，室内耳机 |
| 周六 | 认真做一餐，小份甜品 | 留一个不赶进度的晚上 |
| 周日 | 咖啡或热茶，烘焙点心 | 选下周菜单，给节日留一份期待 |

这是可替换菜单，不要求每天复杂做饭。先到期先用；周末和生日保留小份额，同时服从实际食品状态和标签。中后期用咖啡、茶、香料、罐头和不同烹调方式延续变化，不指望第二年还有所有鲜食品类。日历、收藏的食谱、书、音乐、离线游戏、纪念物和狗的照料一起构成生活节奏；不声称它们能保证人不孤独。

## 冷库和故障后备

外形2.4×1.8m，占地4.32m²；内部约2.0×1.4×2.0m，四层L形架与可进入通路，门内手动解锁、两套测温，冷凝机在外散热。200mm级保温外壳是概念尺寸；围护、地坪隔汽防潮防冻、冷媒、化霜和制冷量须供应商按当地气候设计，模型不是施工图。

正常冷库制冷预算6kWh/日，夏季9、强气候12，包含制冷/风机/化霜留量，是预算而非实测。由旧双冷柜冷冻预算1.5kWh/日替换后，全屋温和15.85、夏季24.85、强气候33.85；124.4kWh估计可用电池在零发电夏季约5.0天（未开空气制水）。原电脑12小时/日保留，持续低日照优先暂停电脑、空调等非必要负载。不得承诺无电长期冻存；该冷库未实测断电保持时间，不能套用满载家用冰柜48小时的经验值。

两台350L空置备用柜轮换试机，按80%名义容积约560L可用，190kg混合包装冻品分项估计约476L（肉1.7、鱼虾2、半成品3、蔬果3、奶酪甜品2、烘焙8、冰淇淋2L/kg）；实际选品（尤其点心、面包、冰淇淋）体积变化较大，必须装箱实测，超体积就减库存或调整品类，不以重量自动证明装得下。先预冷再转存，温度记录决定食品处理。存在公共供电故障同时失冷的风险，因此基础常温主粮不取消。

公寓版保留家用冷柜和冰箱；15楼不直接追加有地坪冷凝水、散热与承载要求的步入冷库。
