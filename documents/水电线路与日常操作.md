# 水电线路与日常操作 R3.4

网页顶栏“水路怎么走”“电路怎么走”分别显示对应功能管线。埋地线会穿透显示，方便追踪，不是把管子和电线铺在聚会区；青色原水、蓝色处理后生活水、绿色滴灌、棕色污水、紫色普通冷凝回收，橙红直流、金色交流。模型有V2菜区控制站、三只分床阀、候选8L稳压罐、干电间B1–B8配电板，可点选看用途。住宅房间布置不变。

## 桶里的水怎样用来浇菜

正常水路：2000L原水罐的西侧低位阀 → P1/P2一用一备的供水泵 → 根据检测结果选的处理 → 合适的末端消毒 → 菜区独立防回流、过滤、减压、定时站V2 → V2.1/2/3三只分床阀 → 每床横管 → 两排滴灌管。支路在RO之前取水，不用RO纯净水浇菜。模型补齐了总管与床头横管，原先中间断开的两排滴灌现在有连接。

食用菜分支只在水质适合用途时启用。雨水可能带微生物和化学污染，滤芯与UV也不是对所有污染物万能；本方案不留“原水直接浇食用菜”的旁路。普通空调冷凝水、RO浓水、厨房和化粪池污水不接菜床。滴灌落到根区，减少碰到可食部分；这不能替代水质管理。

日常按这个顺序：

1. 确认罐有水、来源与处理状态正常，P1可用且P2隔离待用；确认无漏水、泵不空转。
2. 开要种的床V2.1/2/3，闲置床关掉。V2用定时器开关，过滤/减压和防回流器按匹配设备配置；不把软管末端泡进脏水或肥液。
3. 例子：每床两排、每排6个候选2L/h滴头，一床24L/h，三床72L/h。三床运行35分钟约42L；按4L/m²/日参考需求为41.04L。这里是标定起点，不是每天固定浇35分钟的农业处方，雨天、湿土、作物大小都要调。
4. 初次用量杯或计量桶量实际滴头流量；查看远端也出水、床尾能冲洗、接头不漏。用完确认定时阀关闭，按说明清洁过滤器和滴管，不长期放着无人检查。

低液位停灌暂设“罐中剩600L”，这是设计假设；扣200L底部/操作余量后约有400L原水可给生活，按70L/日约5.7天。实际液位传感器、阈值与死水量要标定。停止灌溉不等于生活主水阀也关掉。全罐缺水保护则停泵，防止干转；漏水应隔离相应支路。

约8L稳压罐只为小流量工况预留，不另计备用水；泵最小稳定流量、压力、启停与稳压匹配仍须按实机确认。控制站可留手动操作，但手动旁通仍经过匹配的防回流/过滤/减压，不绕过水质处理。停电定时阀默认关闭，不假定靠地面桶高度就能带动标准滴头；生活先取封装饮水及独立杂用箱低位口，菜床按实际情况暂停。

## 补水、生活和排水分开

屋面主水路高于水罐入口，地面可操作的弃流装置是向下排脏水的支腿，不能让雨水先落地再无动力爬回桶顶。外补接口需要合适的供水压力/转运提升与防污染措施；不是接上任意水管都会自己上水。来源不明时先隔离，不污染整罐。

生活处理水去洗漱等适合用途的龙头；另一路RO进20L日用小箱。独立480L原封装饮水和300L杂用备用不与原水重复计量。厨房先隔油，废油单独收；厕所/生活污水去5m³化粪处理，再去合格后续处理端。雨水溢流另走，不能进化粪池，也不能把池出水当菜水。

## 电从哪里来，怎么分

住宅、机房与棚顶光伏分区 → 匹配的直流隔离/保护/MPPT → 混合逆变系统；三组各12模块电池柜分别经匹配保护、隔离与BMS接入成套系统 → 主隔离与计量 → 干电间B1–B8分路。36模块不能当作可随意并接的电池堆，额定172.8kWh也不是172.8kW输出。

| 分组 | 用途和优先级 |
|---|---|
| B1 | 主冷库、温度告警，基本保冷独立分路 |
| B2 | 转存冰柜、必要照明和通信；与主冷库分路，仍共用上游电源 |
| B3 | 供水P1/P2、UV和水处理，一用一备；减载时保基本供水 |
| B4 | 生活插座、电脑，按需减少 |
| B5 | 做饭、热水、空调等分别设子回路，按功率互锁/限载 |
| B6 | 灌溉控制器/阀门，缺水/低SOC停；不因此停生活泵 |
| B7 | EV专用充电回路；达到家用保底且有足够瞬时余电才充 |
| B8 | 未接负载的隔离预留，不虚算收益 |

平时可选接市电，但逆变、停网隔离及切换必须匹配，不能回送到无保护电网；当前生存预算没有计市电。电线沿干电间及边带走专用通道，与水管分别敷设，穿墙穿地留可检修接口；图中平面交叉不是接线点，也不是确定施工间距/埋深。最终线径、管径、压降、坡度、保护选择性和接地按场地及设备计算，当前不能凭模型定断路器和线缆规格。

EV按家用后2/4kWh交流预算试算，约1.4kW起充是候选参考；功率不够暂停。实际桩需专用保护、漏电/DC泄漏防护与电源匹配。没有假设汽车电池能给屋子倒送电。

## 故障时做什么

| 情况 | 操作逻辑 |
|---|---|
| 原水不足 | 先停V2灌溉，保生活；低到泵保护阈值停泵，改独立备用 |
| UV/水质异常 | 相关处理水分支和食用菜停用，饮食改封装，不开旁路硬撑 |
| 漏水 | 关受影响分支，切相应泵控，修复/清洁验证后再开 |
| 家用电池低 | 先停EV，再停灌溉、空气制水和可选负载，按实测保B1/B2/B3 |
| 主冷库分支故障 | 温度告警，确认两台转存柜有电和温度再转存；上游逆变坏时分路本身不能救供电 |
| 控制器坏 | 使用经预先演练的手动操作卡；不短接安全保护，带电柜不自行拆修 |

匹配灌溉过滤芯、定时阀、减压阀、滴管与接头在二层水务备件箱；电务备件在东架，规格待最终设备锁定。备件清单已同步，不能用外观像的零件替换不同电压/压力/分断等级的器件。
