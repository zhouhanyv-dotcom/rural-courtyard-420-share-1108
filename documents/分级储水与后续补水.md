# 单2000L原水、饮水与地下污水 R3.4

仅一只2000L原水罐，移到净水机房东侧遮护位，常备1800L，设计可取1600L。旧双罐与大棚架移除，不能继续使用8m³/7.2m³或“另一罐满水备用”的旧账。低位阀朝东侧检修通道，盖与防虫通气口在地面可检查；罐体食品接触/室外评级和承载基础仍需按实物选型。

| 水类 | 当前计划实际量 |
|---|---:|
| 原水 | 1800L，设计可取1600L |
| 非饮用杂用备用 | 300L，箱容500L |
| 独立原封装饮水 | 480L：主架450＋一层20＋二层10 |
| 日用RO | 20L，短周转工作水 |
| 合计实际计划存水 | 2600L，水质和用途分别计量 |

生活原水预算70L/日=RO进水22（成品5.5＋浓水16.5）＋其他生活44.5＋冲洗3.5；三床菜区另41.04L/日。1600L停灌约22.9天，含全菜床约14.4天。单罐停用先取独立封装饮水/杂用备用，隔离检修并恢复合格来水；没有第二个大罐。空气制水未实测前保证来水计0。

记录最早批次、入水量、液位、盖网、渗漏、清洗与检测；补新水不重置旧水日期。不明原水不直接喝/刷牙/洗菜，按污染物检测选择处理。封装饮水按标签；自灌应急饮水按CDC建议每6个月更换，日用RO要小量频繁周转，不照搬6个月工作储水。

屋面集水仍只计原住宅＋机房114m²，假设年雨1500mm×效率75%=128.25m³/年，并不保证每日或旱期不断水；新车库和既有棚顶不提前计收益。外部补水及水质可持续性仍待地块确认。

## 化粪池是什么，为什么不能只挖深

厕所等生活污水进入地下池，让部分固体沉淀、浮渣分离、部分有机物分解，再把液体送去合格的后续处理系统。它不是所有污水永久装在里面的大桶，出水也不是能直接饮用或浇食用菜的净水。

此版按约5m³液体处理容积、三格、地下约2m深的位置意向预留，分格留液体通道；地面三个齐平检查盖、既有高位通气与外部清掏路径保留。尺寸只是空间预留，成套产品、水密/抗浮、地下水、盖板承载、池与建筑基础关系均需现场设计。人不下池。

增大容量的目标是减少清掏频率。EPA给出的常见家庭清掏参考为3–5年，至少每3年由合适人员检查；具体受人数、污水量、固体负荷和池大小影响，污泥/浮渣达到阈值要提前清掏，不能保证几年完全不管。若后续没有去向，纯密闭5m³按65L/日仅约77天，存3年会需要约71m³，不能靠一个较深小池冒充解决。

雨水不进化粪系统；厨房先刮渣、油脂分装10L废油桶，湿巾和食物残渣不冲厕。500L名义/450L可用的埋地应急暂存仍仅约6.9天，不当长期终点。最终合格处理/排放端明确标为尚待场地落实，未假造渗坑或地下水吸收能力。
